# Chatbot Portal Project
This project implements a web-based chatbot portal, allowing users to register, log in, and interact with a custom chatbot designed to answer queries and provide information.

## Features
1. User registration and login system. <br>
2. Chatbot interface for handling queries. <br>
3. Default responses for unmatched keywords. <br>
4. Responsive web portal navigation.

## Getting Started:

### Registration
-> Navigate to the Chatbot Portal registration page.  <br>
-> Use your chosen credentials (e.g., username: user2, password: 1234) to create an account.  <br>
-> On successful registration, a message is displayed:  <br>
-> Account created successfully! Please log in.  <br>

### Login
-> Enter the credentials you registered with to log in.  <br>
-> After logging in, you will be redirected to the main chatbot interface.  <br>

### Chatbot Usage
-> Interact with the chatbot by asking queries.  <br>
-> If an unmatched keyword is entered, the chatbot responds with:  <br>

"I'm not sure about that. Could you please rephrase?"  <br>

"Sorry, I don't understand. Can you ask another question?"

## Requirements
-> Web browser (recommended: Chrome, Firefox)  <br>
-> Internet connection
